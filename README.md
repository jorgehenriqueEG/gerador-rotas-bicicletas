# Gerador Rotas Bicicletas
## Descrição do Problema
Um utilitário para definir o itinerário de entrega de um entregador de bicicletas elétricas.
## Requisitos
* Receber uma lista de endereços com distância.
* Aplicar limite de carga de baterias.
* Retornar a sequência otimizada.
## Exemplo de Uso
Entrada: [("Rua A", 12), ("Rua B", 5), ("Rua C", 20)]
Saída: Rua B, Rua A, Rua C
